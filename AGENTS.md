## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

## Pull Requests

When creating a PR automatically with `gh pr create`, always include:

- `--assignee frodriguezmtnz`
- `--label <label>` según el tipo de cambio (convencional commit):
  - `feat` → `enhancement`
  - `fix` → `bug`
  - `docs` → `documentation`
  - `refactor` / `chore` / otros → `enhancement`
